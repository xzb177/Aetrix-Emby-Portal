# Aetrix 安装说明（发行版）

欢迎使用 Aetrix。这份说明用大白话把安装讲完，照着做就行，全程只需要一台装了 Docker 的服务器。程序本体不用你编译，装的时候直接从我们的镜像仓库下载成品，你的机器上不需要装其他任何东西。

## 一、准备

- 一台服务器（Linux），装好 **Docker** 和 **Docker Compose v2**（命令是 `docker compose`，中间是空格）。
- 把你的影视文件放在服务器的一个目录里，比如 `/data/movies`，一会儿要填。
- 准备好我们发给你的两样东西：**授权码**和**镜像拉取凭据**（一组用户名＋密码，专门用来下载程序，装的时候登录一次就行）。再想好你打算用的**域名**（没有域名也可以先用 IP + 端口跑起来，授权绑定域名可以填服务器 IP）。

## 二、安装（五步）

假设发行包解压在 `~/aetrix`：

**第 1 步：进目录、生成配置文件**

```bash
cd ~/aetrix
cp env.example .env
```

**第 2 步：改四处配置**

用任意文本编辑器打开 `.env`，只需要改这四处（其它保持默认）：

1. `SECRET_KEY=` 后面填一串随机密钥，生成命令：
   `python3 -c "import secrets; print(secrets.token_urlsafe(48))"`（没有 python3 就用 `openssl rand -hex 32`）。
2. `POSTGRES_PASSWORD=` 后面填一个数据库密码，自己编一个长一点的。
3. `AETRIX_LICENSE_CODE=` 后面填你的授权码；`AETRIX_LICENSE_DOMAIN=` 后面填你的域名（只填域名本身，如 `media.example.com`，不要带 `https://`）。没填也没关系，装好后可以在管理后台里填。
4. `MEDIA_ROOT=` 改成你放影视文件的目录，比如 `MEDIA_ROOT=/data/movies`。

**第 3 步：登录镜像仓库**

```bash
docker login ghcr.io
```

按提示输入我们随授权码一起发给你的**拉取凭据**（用户名和密码）。显示 `Login Succeeded` 就是登录成功了。这一步只需做一次，之后下载和升级都不用再登录。

**第 4 步：下载程序**

```bash
docker compose pull
```

把这一版的程序全部下载下来，网速快慢决定时间，下载完会显示完成。

**第 5 步：启动**

```bash
docker compose up -d
```

启动完成后：

- 用户端：`http://你的服务器IP:8000/`
- 管理后台：`http://你的服务器IP:8000/admin/`

## 三、确认授权状态

登录管理后台 →「系统设置」→「付费与支付」段里的**软件授权**卡片：

- 状态显示**生效中**就说明授权没问题；
- 授权码或域名没在 `.env` 里填的，在这张卡片里填上，点**保存并校验**即可；
- 显示不对时先点一次**立即校验**，还不行再联系我们（TG：@xiayea）。

## 四、常见问题

**下载时提示没权限 / unauthorized 怎么办？**
多半是没登录，或者拉取凭据输错了。重新执行第 3 步 `docker login ghcr.io` 登录一次再 `docker compose pull`。还不行就是凭据过期或被换发了，联系我们重新发一份，不用重新买。

**怎么升级到新版本？**
不用重新拿安装包。在 `.env` 末尾加一行（有就改）`AETRIX_VERSION=新版本号`，然后：

```bash
docker compose pull
docker compose up -d
```

数据不会丢（见下一条）。想退回旧版本同理，把版本号改回去再执行这两条命令。

**数据存在哪？升级会丢吗？**
数据库、海报等数据都在 Docker 数据卷里（`postgres_data`、`aetrix_data`），不在程序里，所以换版本、重装都不会丢。重要数据请另外定期备份整个部署目录和数据卷。

**换服务器了怎么办？**
在新服务器上按上面五步装好（拉取凭据可以继续用同一份），再到管理后台软件授权卡片里点「立即校验」。如果提示绑定不匹配，联系我们重置一次绑定就能继续用，不用重新买。授权本来就允许换绑：30 天内可换 1 次（自助换绑在二期上线，目前联系我们处理）。

**断网会不会停播？**
不会。软件会把许可证缓存在本机：授权服务器连不上时一切照常；授权到期后还有 **7 天宽限期**，宽限内播放不受影响。到期前 30 天起，管理后台的软件授权卡片会提醒你续费。

**校验会上传我的数据吗？**
不会。校验只发四样东西：授权码、机器指纹的哈希（一串算出来的编号，看不出机器信息）、绑定域名、软件版本号。不发任何用户、片库、播放记录。

**端口想改？**
改 `.env` 里的 `AETRIX_PORT`，再 `docker compose up -d`。
