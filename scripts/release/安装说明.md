# Aetrix 安装说明（发行版）

欢迎使用 Aetrix。这份说明用大白话把安装讲完，照着做就行，全程只需要一台装了 Docker 的服务器。

## 一、准备

- 一台服务器（Linux），装好 **Docker** 和 **Docker Compose v2**（命令是 `docker compose`，中间是空格）。
- 把你的影视文件放在服务器的一个目录里，比如 `/data/movies`，一会儿要填。
- 准备好你的**授权码**和你打算用的**域名**（没有域名也可以先用 IP + 端口跑起来，授权绑定域名可以填服务器 IP）。

## 二、安装（四步）

假设发行包解压在 `~/aetrix`：

```bash
cd ~/aetrix
cp env.example .env
```

用任意文本编辑器打开 `.env`，只需要改这四处（其它保持默认）：

1. `SECRET_KEY=` 后面填一串随机密钥，生成命令：
   `python3 -c "import secrets; print(secrets.token_urlsafe(48))"`
2. `POSTGRES_PASSWORD=` 后面填一个数据库密码，自己编一个长一点的。
3. `AETRIX_LICENSE_CODE=` 后面填你的授权码；`AETRIX_LICENSE_DOMAIN=` 后面填你的域名（只填域名本身，如 `media.example.com`，不要带 `https://`）。没填也没关系，装好后可以在管理后台里填。
4. `MEDIA_ROOT=` 改成你放影视文件的目录，比如 `MEDIA_ROOT=/data/movies`。

然后一条命令启动：

```bash
docker compose up -d --build
```

第一次构建要几分钟。启动完成后：

- 用户端：`http://你的服务器IP:8000/`
- 管理后台：`http://你的服务器IP:8000/admin/`

## 三、确认授权状态

登录管理后台 →「系统设置」→「付费与支付」段里的**软件授权**卡片：

- 状态显示**生效中**就说明授权没问题；
- 授权码或域名没在 `.env` 里填的，在这张卡片里填上，点**保存并校验**即可；
- 显示不对时先点一次**立即校验**，还不行再联系我们（TG：@xiayea）。

## 四、常见问题

**换服务器了怎么办？**
在新服务器上按上面步骤装好，再到管理后台软件授权卡片里点「立即校验」。如果提示绑定不匹配，联系我们重置一次绑定就能继续用，不用重新买。授权本来就允许换绑：30 天内可换 1 次（自助换绑在二期上线，目前联系我们处理）。

**断网会不会停播？**
不会。软件会把许可证缓存在本机：授权服务器连不上时一切照常；授权到期后还有 **7 天宽限期**，宽限内播放不受影响。到期前 30 天起，管理后台的软件授权卡片会提醒你续费。

**数据存在哪？升级会丢吗？**
数据库、海报等数据都在 Docker 数据卷里（`postgres_data`、`aetrix_data`）。升级 = 拿到新发行包后覆盖源码文件，再跑一次 `docker compose up -d --build`，数据不会丢。重要数据请另外定期备份整个部署目录和数据卷。

**校验会上传我的数据吗？**
不会。校验只发四样东西：授权码、机器指纹的哈希（一串算出来的编号，看不出机器信息）、绑定域名、软件版本号。不发任何用户、片库、播放记录。

**端口想改？**
改 `.env` 里的 `AETRIX_PORT`，再 `docker compose up -d`。
